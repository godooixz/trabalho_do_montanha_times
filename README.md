# Gerador de Confrontos

**Trabalho Avaliativo: Um algoritmo, diferentes linguagens**

**Unidade Curricular:** Algoritmos e Programação

**Dupla:** Bernardo e Godoi (Gabriel)

Este repositório contém os códigos-fonte e o relatório do trabalho prático em três linguagens diferentes: Java, C# e Rust.


## Como executar os programas

# Java

**É necessário ter o JDK instalado.**

cd java

javac Main.java

java Main


# C# (.NET)

**É necessário ter o SDK do .NET instalado.**

cd csharp

dotnet run


# Rust (Cargo)

**É necessário ter o Rust e o Cargo instalados.**

cd rust

cargo run
